# 감행의 철학 — 설계도 (ceoai.kr/growth 역산 기반)

## 원본 구조 (CEO AI "AI 자율성장시스템")
훅(매일 똑똑해지는 회사) → 루프 수학(1.01^52=1.68, 1.01^104=2.81, 0.99^n 경고) → 테슬라 유비(개입 순간 수집) → 방법(다섯 고리: 기록·채점·진단·검증적용·결재) → 오답 5원인/처방 → 자동/승인 위계 + 금지(자기 시험 자기 채점) → 구축 사례 → CEO 월간 7질문 → 90일 로드맵 → 상담 CTA.
특징: 가격·후기·희소성 장치 없음. 신뢰는 저자 본인의 칼럼·강의·논문·사례에서 나옴. 합니다체, 숫자 중심, 다크 네이비.

## 철학판 대응표
| 원본 | 감행의 철학 |
|---|---|
| 회사의 AI | 나 |
| 업무 기록 + 사람의 수정 | 감행일지 + 남이 고쳐 준 말 |
| 평가셋 20~50건 | 나의 신조 7~12문장 (시험지) |
| 오답 5원인 | 앎 부족·모호한 원칙·환경·판단·기준 오류 |
| 섀도→5%→50%→전면 | 리허설→하루 실험→한 달 부분 감행→전면 |
| 60초 롤백 | 되돌릴 수 있는/없는 결정 구분 |
| CEO 결재 | 증인·공동체 앞 서약 |
| 테슬라 FSD | 소크라테스·세네카·프랭클린·니체·듀이 |
| 구축 사례 | 고전의 루프 + 모두의 철학 연재 |
| 상담 신청 | 네이버 프리미엄콘텐츠 구독 |

## 종교의 형식
의례: 매일 저녁 심문(5분) · 매주 감행 하나 · 매월 일곱 질문 · 분기 건너가기 선언 · 매년 신조 개정.
세 가지 금지: 교주 없음 / 떠날 자유 / 모든 신조는 개정 가능.
