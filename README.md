# moduphilosophy
모두의 철학

동서양 철학과 AI 시대를 함께 읽는 연재 「모두의 철학」의 원고와 기획 자료를 모아 둔 저장소입니다. 네이버 프리미엄콘텐츠 채널로 운영할 예정입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `posts/` | 연재 원고 (창간사, 모심의 존재론, 동학과 AI) |
| `plans/` | 연재 기획 — 자동화의 근원 10꼭지 목차, 감행의 철학 설계도 |
| `docs/` | 채널 세팅 가이드, 신청서·채널 소개문, URL 후보 |
