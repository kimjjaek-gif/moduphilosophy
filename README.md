# moduphilosophy
모두의 철학

## 모두의 철학 X 철기시대

철학과 기술이 만나는 자리에서 한 주를 읽는 코너입니다. 매주 열 가지 이슈를 고르고, 각 이슈가 삶에 던지는 물음을 고전에 비춰 읽습니다.

- 사이트: https://kimjjaek-gif.github.io/moduphilosophy/
- 대문(아카이브): `index.html` — `weeks.json`을 읽어 최신 호부터 보여 줍니다.
- 주간 호: `weeks/<시작일>.html` (예: `weeks/2026-11-08.html`)

## 새 호 추가하는 법 (매주)

1. 지난 호 파일을 복사해 새 이름으로 저장합니다. 예: `weeks/2026-11-15.html`
2. 새 파일에서 기간, 열 가지 이슈, 출처, 이번 주의 물음을 고칩니다.
3. `weeks.json` 배열에 항목 하나를 추가합니다.

```json
{
  "no": 2,
  "slug": "2026-11-15",
  "period": "2026. 11. 15 — 11. 21",
  "title": "이번 호 제목",
  "summary": "목록에 보일 두세 줄 요약",
  "keywords": ["키워드1", "키워드2"],
  "top3": ["1위 이슈", "2위 이슈", "3위 이슈"]
}
```

4. 커밋하고 푸시하면 1~2분 뒤 사이트에 반영됩니다. 대문은 `slug` 기준 최신 호를 맨 위에 강조합니다.
